Sketchy is a fusion of a drawing game and a social deduction game. So the name Sketchy (Sketch -> draw, sketchy -> suspicious)
# How to play:
Requires a minimum of 4 players to start.
Once the host starts the game, every player is assigned a role. They can be either an artist or an imposter.
Each person has 15s to draw something in the shared canvas. 
The artists should try to draw hints of the word they are assigned without making it blatantly obvious to the imposter.
The imposter should ideally try to blend in and try to deduce what the word is and try to continue the drawing.
All players can request a vote at an point of time. If the majority requests a vote. The vote session begins.
If the imposter is voted out, good game.
Else he continues to play amidst the artists.
If 2 or more people are voted out falsely, imposter wins.
